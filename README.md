# P_BULLE_DOCKER  

## Conteneurs inclus

- **PHP** : Conteneur exécutant le serveur PHP pour faire tourner l'application.
- **MariaDB** : Conteneur de base de données pour stocker les données de l'application.
- **PHPMyAdmin** : Conteneur permettant d'administrer la base de données via une interface web conviviale.

## Lancer le projet

Pour démarrer les conteneurs, il suffit d'utiliser la commande suivante depuis le répertoire contenant le fichier `docker-compose.yml` :

```bash
docker-compose up -d --build
